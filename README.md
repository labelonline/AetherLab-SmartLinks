# AetherLab Smart Links

Public renderer for Smart Links created in the main AetherLab dashboard.

- Main dashboard: https://labelonline.github.io/AetherLab/
- Public Smart Links: `https://labelonline.github.io/AetherLab-SmartLinks/#<slug>`

This repository is intentionally separate from the main dashboard. Do not copy its `index.html` into the AetherLab repository.
